# Contributing to velyrlabs

Thanks for your interest. Each repository may add its own `CONTRIBUTING.md`;
when it does, that file takes precedence over this one.

- Runtime contributions: read the
  [Velyr contributing guide](https://github.com/velyrlabs/velyr/blob/main/CONTRIBUTING.md).
- Before larger changes, open an issue so the approach can be agreed first.
- All participation follows the [Code of Conduct](CODE_OF_CONDUCT.md).
- Security problems are reported privately, see [SECURITY.md](SECURITY.md).

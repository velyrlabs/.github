# Getting help

- Questions and ideas: open a discussion or issue on
  [velyrlabs/velyr](https://github.com/velyrlabs/velyr/issues).
- Bugs: use the bug report template and include `velyr --version` and a minimal
  reproduction.
- Security problems: report privately, see [SECURITY.md](SECURITY.md).

Velyr is alpha software maintained by a small team; responses are best effort.
